# เริ่มใช้ GMK Documentary Maker — Build 054

GMK ใช้ทำสารคดีจากหัวเรื่องหรือรีเสิร์ชของ Gemini ที่เก็บใน Google Drive เปิดโปรแกรมแล้วเลือก **โปรเจกต์สารคดี** เพื่อสร้างเรื่องใหม่ นำเข้าเอกสาร หรือเปิดงานเดิม

## เปิดโปรแกรม

บน CachyOS เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน `./INSTALL_GMK.sh` ครั้งแรก จากนั้นเปิด **GMK Documentary Maker** จากเมนูแอป หรือรัน `./START_GMK.sh`

บน Windows ใช้ `INSTALL_GMK.cmd` ครั้งแรก แล้วเปิดด้วย `START_GMK.cmd`

## ทำงานในโปรเจกต์

1. เริ่มจากหัวเรื่องใหม่ หรือเลือกเอกสาร **LEMiNO Script** ใน Drive/ไฟล์จากเครื่อง
2. เปิด **พื้นที่ทำสารคดี** และตั้งโจทย์: ผู้ชม คำถามหลัก ขอบเขต และความยาว
3. ที่ **ภาพรวมและงานถัดไป** กด **ตรวจความพร้อมทั้งโปรเจกต์** เพื่อดูว่าขั้นใดยังขาด แล้วกด **ทำขั้นตอนถัดไป**
4. ตรวจแหล่งข้อมูลและถ้อยคำในบท วางเรื่องและเชื่อมฉากเข้าระบบผลิต
5. สร้างหรือนำเข้าเสียง ค้น/ดาวน์โหลดฟุตเทจ เลือกช่วงตัด เปิดตรวจภาพและเสียง แล้วบันทึกผลตรวจ
   จากนั้นกด **เชื่อมภาพที่ตรวจแล้วเข้าข้อมูลผลิต** → **ตรวจไฟล์และความพร้อม** → **เชื่อมไฟล์และช่วงตัดที่ตรวจแล้ว**
   กด **ตรวจความครอบคลุมภาพกับเสียง** → **ตรวจภาพและความยาวเสียง** → **บันทึกผลตรวจภาพ** แก้ฉากที่ขาดก่อน หากเลือกใช้ภาพในคลังนี้แล้ว ให้เลือกหยุดค้นและระบุเหตุผล
6. ใส่ดนตรี/ชื่อฉาก ตรวจไทม์ไลน์ และเรนเดอร์ MP4
7. ดูและฟังทั้งเรื่อง ยืนยันผลตรวจครบทุกด้าน สร้างชุดส่งออก แล้วส่งและตรวจสำเนาบน Drive

งานและไฟล์ต้นฉบับเก็บใน `~/GMK Projects/` การส่ง Drive ไม่สำเร็จจะเก็บงานไว้ในเครื่องเพื่อส่งซ้ำ

ดูรายละเอียดที่ [คู่มือพื้นที่ตัดต่อ](EDITOR_GUIDE_TH.md) และ [เริ่มใช้บน CachyOS](QUICK_START_CACHYOS_TH.md)

## สถานะจริง

หน้าหลักเหลือเฉพาะโปรเจกต์สารคดีและการตั้งค่า การทำสารคดีอัตโนมัติครบวงจรยังอยู่ระหว่างพัฒนา: การอนุมัติขั้นสุดท้ายในข้อมูลผลิตหลักและการทดสอบส่งมอบสารคดีจริงยังไม่ครบ หน้าภาพรวมจะแสดงงานที่ค้างโดยไม่ประกาศว่าเสร็จจากการเรนเดอร์หรืออัปโหลดเพียงอย่างเดียว
